免费模型管理

同步到 CPA 的模型

    
取消勾选的模型不会再出现在 CPA 的模型列表中，客户端直接请求也会被拒绝；控制台里的账号、额度与渠道设置不受影响。选择结果保存在插件的私有数据目录，升级插件不会丢失。

    

      
      

        
        
        
      

    

    

    
    
    
    
    
    
      
      
    
    
  
    
  
    
    
    更新插件
    
    
    直接在这里更新，不必登录服务器敲命令。CPA 从正式 Release 下载对应平台安装包、校验 SHA-256 并尝试热加载；只有确认新版正在运行，才会显示更新成功。
    
    
    
      
    正式发布通道 · 由 CPA 原生安装器执行
    
      点击检查更新，确认当前平台是否有可安装的新版本。
      
      
    
        
        
        
        
      
    
      
    安装前会再次确认。首次可能需要添加本插件更新源；保留账号数据和其他更新源。热加载可能中断当前请求，若宿主要求重启会明确提示，不会自动重启 CPA。
    
    
    
    
    
      源码更新（开发者备用）
      
    仓库提交不等于正式安装包。没有 Release 或需要自行编译时，仍可在服务器的干净源码仓库执行更新命令。
    
      
    
      尚未检查源码。
      
    node scripts/update.mjs --apply --plugin-dir /你的/CPA/plugins
    
      
    将路径改为实际插件目录，需要 Git、Go、Node 和 C 编译器。此备用命令会备份旧动态库，不自动重启 CPA。
    
    
    
  
    
  
    连接说明
    客户端仍连接 CPA，默认模型 ID 带 ofm/ 前缀。渠道登录或模型开关变更后，点击“同步模型到 CPA”。控制台的数据操作始终经过 CPA 管理鉴权。部分厂商使用自己的 OAuth 回调规则，可能仍需按厂商提示转发回调端口。
    
  
    直接基于 原项目 Our Free Model，独立适配 CPA。参考二开不是源码依赖。原项目授权与上游服务限制仍然适用。
